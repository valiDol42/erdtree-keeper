# Безопасность

## Что программа может и чего не может

Erdtree Keeper работает с правами обычного пользователя и трогает ровно три вещи:

1. Читает папку сохранений `%APPDATA%\EldenRing`.
2. Пишет копии в папку, которую вы выбрали.
3. Пишет один файл настроек рядом с собой.

Плюс одно действие по явной команде: «Восстановить в игру» перезаписывает файл сохранения,
предварительно сложив прежний в подпапку `Перед восстановлением`.

Сетевого кода в программе нет, и это проверяется по готовому файлу:

```
> dumpbin /dependents ErdtreeKeeper.exe

ADVAPI32.dll        bcrypt.dll          KERNEL32.dll
ole32.dll           OLEAUT32.dll        api-ms-win-crt-*.dll
```

Ни `ws2_32.dll`, ни `winhttp.dll`, ни `wininet.dll` в импорте нет - без них программа в
Windows не может открыть сетевое соединение.

Прав администратора программа не запрашивает - это закреплено в манифесте
(`requestedExecutionLevel level="asInvoker"`).

## Как убедиться, что скачанный файл настоящий

**Контрольная сумма.** На странице каждого релиза лежит файл `SHA256SUMS.txt`. Сравните:

```powershell
Get-FileHash .\ErdtreeKeeper.exe -Algorithm SHA256
```

Ту же сумму программа считает сама - в окне «О программе».

**Происхождение сборки.** Релизы собираются GitHub Actions и подписываются attestation.
Проверка через [GitHub CLI](https://cli.github.com):

```bash
gh attestation verify ErdtreeKeeper.exe --repo <owner>/erdtree-keeper
```

Успешная проверка означает, что этот файл собран именно из кода в этом репозитории и
именно тем рабочим процессом, а не собран кем-то у себя и подложен под тем же именем.

**Своя сборка.** Самый надёжный способ - собрать самому:

```bash
dotnet publish src/ErdtreeKeeper/ErdtreeKeeper.csproj -c Release -r win-x64 -o out
```

## Предупреждения Windows

У программы нет сертификата подписи кода: он стоит денег и выдаётся на юридическое лицо.
Поэтому при первом запуске Windows покажет окно SmartScreen «Windows защитила ваш
компьютер» с кнопкой «Подробнее» → «Выполнить в любом случае».

Это сообщение говорит только об отсутствии у файла репутации, а не о вредоносности.
Отдельные антивирусы по той же причине иногда помечают свежие неподписанные программы как
подозрительные - это ложное срабатывание. Если сомневаетесь, соберите программу сами:
инструкция выше, весь код открыт.

Мы **никогда** не будем просить отключить антивирус или добавить программу в исключения.
Просьба отключить защиту - типичный признак вредоносной программы, и относиться к ней надо
соответственно, от кого бы она ни исходила.

## Как сообщить об уязвимости

Откройте issue в репозитории. Если проблема серьёзная и её не стоит публиковать сразу -
напишите об этом в issue без подробностей, договоримся о приватном канале.

Что интересует в первую очередь:

- Любой способ заставить программу записать файл за пределами папки снимков и папки игры.
- Любая ситуация, в которой сейв игрока теряется без резервной копии.
- Любое обращение в сеть.
