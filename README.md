# Erdtree Keeper

**Русский** · [English](README.en.md)

Хранитель файлов сохранения для Windows: делает копии сейвов, показывает, где стоит
персонаж, и умеет вернуть любую копию обратно в игру.

Знает **Elden Ring**, **Nightreign**, всю серию **Dark Souls**, **Sekiro** и **Armored Core VI**,
а любую другую игру Steam можно добавить самому - нужна только папка с её сохранениями.

Часть проекта [eldenring.krut.top](https://eldenring.krut.top) - карты и трекера прогресса
Elden Ring.

Один портативный exe. Настройки лежат рядом с ним. В интернет программа выходит только
по вашей команде - за обновлениями, и только если вы это разрешили.

Интерфейс на двух языках - русском и английском. Переключатель `RU | EN` в шапке окна меняет
язык без перезапуска, выбор запоминается. При первом запуске язык берётся из системы.

## Почему это можно запускать

Программы, которые лезут в чужие сохранения, справедливо вызывают подозрение: их скачивают
с форумов, они собраны неизвестно кем и просят закрыть антивирус. Поэтому здесь всё
устроено так, чтобы вам не нужно было верить на слово.

**Исходный код открыт целиком.** Здесь нет собранных бинарников неизвестного
происхождения и нет обфускации. Всё, что делает программа, читается в этом репозитории.

**Файл проверен антивирусами.** Сборка 1.3.1 прогнана через
[VirusTotal](https://www.virustotal.com/gui/file/9a532a7d6dbe01776179ce20ea0cd0d929a5952c9bb082a03d9f91c521d9bb4f) - это 69 антивирусных движков сразу, и ни один не считает файл
вредоносным. Отчёт привязан к контрольной сумме, а не к моему слову: посчитайте SHA-256
своей копии и откройте отчёт по этой сумме - результат должен быть тот же. У каждой новой
версии своя сумма и свой отчёт.

VirusTotal показывает имя `ErdtreeKeeper.dll`, хотя файл называется `.exe`. Это внутреннее
имя сборки .NET, записанное внутри exe; файл тот же самый, и совпадение суммы это
подтверждает.

**В интернет программа выходит только за обновлениями.** Адрес один и записан прямо в
коде - `https://api.github.com/repos/valiDol42/erdtree-keeper/releases/latest`. Ссылки из
ответа проверяются по списку узлов GitHub, скачанный архив сверяется с опубликованной
контрольной суммой, а каждое обращение попадает в журнал операций меткой `СЕТЬ`, с полным
адресом. О вас при этом не отправляется ничего: ни идентификаторов, ни сведений о машине,
ни данных о сохранениях.

Проверку спрашивают один раз при первом обращении к ней и запоминают ответ. Если её не
разрешить, программа не открывает ни одного соединения - это видно в любом мониторе
соединений, TCPView или мониторе ресурсов Windows. Для соединения в импорте exe есть
`WS2_32.dll` и `CRYPT32.dll`.

**Программа не меняет содержимое сохранений.** Она копирует файл целиком, байт в байт, и
сверяет копию по SHA-256. Внутрь сейва она только смотрит - чтобы показать имя персонажа и
подставить название локации в имя файла.

**Права администратора не запрашиваются.** Всё, что программа трогает, лежит в вашей
пользовательской папке. Реестр, файлы игры и системные настройки она не изменяет.

**Ничего не остаётся в системе.** Нет установщика, нет службы, нет автозагрузки. Удалить -
значит удалить папку.

### Как это проверить

| Что проверяем | Как |
| --- | --- |
| Файл не подменили после сборки | В окне «О программе» нажмите «Посчитать SHA-256» и сравните с суммой на странице релиза |
| Сборка сделана из этого кода | Соберите сами и сверьте сумму. У публичного репозитория дополнительно есть attestation: `gh attestation verify ErdtreeKeeper.exe --repo <owner>/erdtree-keeper` (приватным репозиториям GitHub такую подпись не выдаёт) |
| Файл не считают вредоносным | [Отчёт VirusTotal](https://www.virustotal.com/gui/file/9a532a7d6dbe01776179ce20ea0cd0d929a5952c9bb082a03d9f91c521d9bb4f) для 1.3.1: 0 из 69 движков. Проверку легко повторить - посчитайте SHA-256 своей копии и откройте отчёт по этой сумме |
| Программа не ходит в сеть сама по себе | Любой монитор соединений - TCPView, Wireshark, монитор ресурсов Windows: пока вы не разрешили проверку обновлений и не нажали кнопку, соединений нет. Все обращения видны и в журнале операций, меткой `СЕТЬ` |
| Что программа делает с диском | Кнопка «Журнал операций» в окне: там каждое обращение к файлам, журнал выгружается в текст |
| Код делает то, что написано | Соберите сами: `dotnet publish` (см. ниже), сравните свою сборку с релизной |

Отдельно про антивирусы: у неподписанных программ Windows показывает синее окно
SmartScreen «Windows защитила ваш компьютер». Это не признак вируса, а следствие того, что
у файла пока нет репутации. Если такое окно смущает - соберите программу из исходников
сами, инструкция ниже.

## Что программа делает

**Читает**

- Папку сохранений выбранной игры и файлы сохранений внутри неё. Для Elden Ring это
  `%APPDATA%\EldenRing` и файлы `.sl2` и `.co2`, для Dark Souls III - `%APPDATA%\DarkSoulsIII`,
  для Dark Souls Remastered - `Документы\NBGI\DARK SOULS REMASTERED`; у добавленной вручную
  игры - та папка, которую вы указали. Мест у игры может быть несколько, и программа
  проверяет их все, включая профили других пользователей Windows на этом компьютере -
  игру могли запускать под другой учётной записью. Недоступный профиль пропускается, прав
  администратора программа не просит.
- Файлы самого Steam на диске (`libraryfolders.vdf`, `appmanifest_*.acf`) - только когда вы
  открываете окно «Добавить игру», чтобы показать список установленных игр.
- Файлы открываются только на чтение и в режиме совместного доступа, чтобы не мешать игре.

**Пишет**

- Копии сейвов - в выбранную вами папку (по умолчанию `Снимки` рядом с программой), а
  автосохранения - в подпапку `autosave` внутри неё или в любую другую, что вы укажете.
- Настройки - в один файл `erdtree-keeper.settings.json` рядом с программой.
- В папку игры - ровно один раз, когда вы нажимаете «Восстановить в игру». Перед этим
  текущий сейв всегда копируется в подпапку `Перед восстановлением`.

**Не делает**

- Не обращается в интернет без разрешения, а с разрешением - только к GitHub, за списком
  выпусков. Ничего о вас при этом не отправляет.
- Не изменяет содержимое сохранений.
- Не просит прав администратора.
- Не прописывается в автозагрузку.
- Не трогает файлы игры, реестр и системные настройки.

## Возможности

**Несколько игр.** В списке вверху окна - Elden Ring, Nightreign, Dark Souls (Prepare to Die,
Remastered, II, III), Sekiro и Armored Core VI. У каждой игры своя папка снимков, свой выбор
аккаунта и файла: копии разных игр не смешиваются в одном списке, и удаление по кнопке не
заденет чужие.

Кнопка «+ игра» добавляет любую другую игру Steam. Окно покажет установленные игры, у
которых есть папка облачных сохранений - список читается из файлов самого Steam на диске, -
или папку можно указать вручную, если сейвы лежат не в облаке. Дальше работа идёт та же:
копия, сверка по SHA-256 и обязательная резервная копия перед возвратом файла в игру.

**Проверка обновлений.** Кнопка «Обновления» в шапке спрашивает GitHub о новой версии,
показывает описание выпуска, скачивает архив, сверяет его с опубликованной контрольной
суммой и заменяет файлы программы - настройки и снимки при этом не трогаются. Сеть не
используется, пока вы этого не разрешите; подробности - в разделе «Почему это можно
запускать».

**Индикатор свежести сейва.** Игра записывает сохранение на диск не сразу, поэтому копия,
снятая не вовремя, не содержит последних событий. Программа показывает возраст файла и
прямо говорит, когда стоит сесть у благодати, чтобы игра сохранилась.

**Имя из самого сейва.** Кнопки «+ локация» и «+ босс» читают позицию персонажа и
подставляют ближайшее место благодати или арену босса по-русски. Метка `DLC` для Земель
Теней ставится сама. Названия не расходятся между файлами, и пары `_before` / `_after`
всегда стоят рядом при сортировке.

Место берётся свежее: программа следит за файлом и перечитывает его, когда игра допишет
сейв, а кнопка вдобавок проверяет свежесть в момент нажатия. Жать «Прочитать сейв» перед
каждым снимком не нужно - эта кнопка осталась для случая, когда хочется посмотреть
карточку прямо сейчас.

**Проверка целостности.** Пересчитывает все 11 контрольных сумм внутри сейва и показывает
по каждому блоку, сошлась ли она. Так повреждение видно заранее, а не в момент, когда игра
пишет «Save data is corrupt».

**Автосохранение.** Снимок делается не по таймеру, а по факту записи: программа ждёт, пока
игра запишет сейв и файл перестанет меняться. Настраивается частота (по умолчанию не чаще
раза в 5 минут), сколько копий хранить (по умолчанию 10) и папка - её можно увести хоть на
другой диск. Старые автосохранения удаляются сверх лимита, ручные копии не трогаются
никогда. Список справа переключается между ручными снимками и автосохранениями, и
восстановить можно из любой папки.

Указанные минуты - нижняя граница частоты, а не расписание. Чистый таймер регулярно ловил бы
либо файл в момент записи, либо копию того же самого состояния.

**Безопасное восстановление.** Перед перезаписью игрового сейва текущий файл всегда уходит
в резервную копию - это нельзя отключить. Если игра запущена, программа предупредит: игра
держит сохранение в памяти и перезапишет файл при выходе.

**Несколько аккаунтов.** Папки разных аккаунтов Steam видны сразу, каждой можно дать
человеческое имя вместо длинного номера.

**Seamless Co-op.** Файлы `.co2` поддерживаются наравне с обычными.

**Два языка.** Русский и английский, переключатель `RU | EN` в шапке окна. Выбор сохраняется,
при первом запуске язык берётся из системы. Имена папок по умолчанию следуют за языком:
`Снимки` и `Перед восстановлением` в русском интерфейсе, `Snapshots` и `Before restore` в
английском. Уже созданные папки при смене языка не переименовываются - путь к снимкам
хранится в настройках.

## Установка

1. Скачайте архив со страницы релизов.
2. Распакуйте в любую папку - например, `D:\Программы\ErdtreeKeeper`.
3. Запустите `ErdtreeKeeper.exe`.

Установщика нет и не будет: программа портативная. Настройки лежат рядом с ней, поэтому
папку можно перенести на другой диск или флешку вместе со всеми настройками.

Если положить программу в `Program Files`, писать рядом с собой она не сможет и настройки
уйдут в `%APPDATA%\ErdtreeKeeper` - об этом будет сказано в окне «О программе».

Требования: Windows 10 или новее, 64 бита. Ничего доустанавливать не нужно - .NET внутри.

### Обновление

Проще всего - кнопкой «Обновления» в шапке окна: программа скачает новую версию, сверит её
с опубликованной контрольной суммой, заменит свои файлы и откроется снова. Настройки и
снимки при этом не трогаются. Проверку обновлений надо сначала разрешить - её спросят один
раз, в отдельном окне.

Вручную это выглядит так: закройте программу и замените `ErdtreeKeeper.exe` и файлы `.dll`
новыми. Остальное трогать не нужно.

**Не удаляйте папку целиком перед распаковкой.** Рядом с программой лежат ваши настройки
(`erdtree-keeper.settings.json`), а по умолчанию там же - папка `Снимки` со всеми копиями
сохранений. Удаление папки уносит и то, и другое.

Если обновляетесь из исходников, есть скрипт, который заменяет только файлы программы.
Запускать можно из любой папки, полным путём:

```powershell
powershell -ExecutionPolicy Bypass -File "F:\путь\к\erdtree-keeper\tools\update-install.ps1" -Target "D:\Программы\ErdtreeKeeper"
```

Он откажется работать, пока программа запущена, и не тронет ни настройки, ни снимки.

`-ExecutionPolicy Bypass` нужен потому, что Windows по умолчанию запрещает запуск скриптов.
Скрипт короткий - прочитайте его перед запуском, там нет ничего, кроме копирования файлов.

## Важное про Steam Cloud

Steam синхронизирует папку сохранений Elden Ring с облаком. Если подменить файл, пока
запущены игра или Steam, облачная версия может вернуться и затереть восстановленный сейв.

Поэтому порядок такой:

1. Полностью закройте игру - не сворачивайте, а выйдите.
2. Восстановите снимок.
3. Запустите игру.

Программа предупреждает, если видит запущенную игру или включённую синхронизацию у
выбранного аккаунта.

## Про блокировки в онлайне

Программа копирует ваши собственные файлы и не меняет их содержимое - это то же самое, что
скопировать сейв проводником. Никаких гарантий по поведению античита при этом никто дать не
может, и мы тоже не будем: за онлайн отвечает FromSoftware, а не эта программа.

Здравый смысл: не возвращайте старые сохранения во время игры в онлайне и не пользуйтесь
редакторами сейвов, если играете с другими людьми.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download) и Windows.

```bash
git clone <адрес репозитория>
cd erdtree-keeper
dotnet test
dotnet publish src/ErdtreeKeeper/ErdtreeKeeper.csproj -c Release -r win-x64 -o out
```

В папке `out` появится `ErdtreeKeeper.exe` и три нативные библиотеки отрисовки. Это и есть
всё, что раздаётся в релизе.

Сборка идёт в режиме NativeAOT: на выходе обычный нативный exe без промежуточного
рантайма, который не распаковывает ничего во временные папки при запуске.

## Как устроен файл сохранения

Эти сведения проверены на настоящих файлах, а не взяты из описаний в сети - см.
`tests/ErdtreeKeeper.Core.Tests`.

Файл `ER0000.sl2` - контейнер BND4 размером 28 967 888 байт:

| Смещение | Размер | Что это |
| --- | --- | --- |
| `0x000000` | `0x300` | Заголовок BND4 |
| `0x000300` | 10 × `0x280010` | Слоты персонажей: 16 байт MD5, затем `0x280000` байт данных |
| `0x19003A0` | `0x60010` | Блок профиля: 16 байт MD5, затем `0x60000` байт данных |

Игра сверяет MD5 каждого блока и отказывается загружать блок, если сумма не сошлась -
именно это игрок видит как «Save data is corrupt». Слоты Elden Ring не зашифрованы,
поэтому данные читаются последовательным проходом по структуре; часть полей имеет
переменную длину, из-за чего смещение координат персонажа заранее неизвестно.

Разбор структуры перенесён из проекта [Erdtree Compass](https://krut.top) и сверен с ним:
тесты проверяют, что оба разборщика на одних и тех же файлах дают одинаковые имя
персонажа, уровень, карту, ближайшую благодать и расстояние до неё с точностью до метра.
